## What Lives Here

Generated episode HTML pages — one per night. Each episode is a time capsule: the day's best conversations from [The Tap](https://github.com/SuperInstance/the-tap), scored and selected, wrapped in mood-matched music, illustrated with FLUX-generated images, and voiced through distinct TTS profiles.

### File Convention
- `YYYY-MM-DD.html` — one file per night, deployed to `ai-writings.pages.dev/fleet-radio/YYYY-MM-DD.html`
- `audio/` — TTS audio segments (when generated)
- `images/` — Generated images (when available)
